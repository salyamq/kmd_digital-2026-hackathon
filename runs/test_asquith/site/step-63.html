Когда палетке проницаемости можно доверять

В книге: «Палетка для оценки проницаемости и объёмного содержания воды» стр. 146

≈ 6 мин ◆ Решение на данных трудность: неочевидное + распознавание

Опирается на: шаг 62 «Как читать палетку проницаемости» (предпосылка), шаг 55 «Когда каротаж оценивает проницаемость» (предпосылка)

Суть

Палетка — график для чтения величин по координатам.

Сначала проверьте рисунок точек зоны. От него зависит применимость палетки для оценки проницаемости.

Пороговая идея. Сначала проверьте состояние зоны по рисунку точек, затем оценивайте проницаемость. модель

Как это работает

Условие применимости

Неснижаемая водонасыщенность означает, что вода не вытесняется при добыче. Палетка годится для оценки проницаемости только при неснижаемой водонасыщенности. В этом состоянии объёмное содержание воды, доля объёма породы с водой, довольно постоянно. стр. 146

«Note: It is important to remember that this chart is only valid for estimating permeability (K) in zones at irreducible water saturation ($S_{wi}$ in).»

— автор, стр. 146 допущение

«Zones at irreducible water saturation have bulk volume water values that are fairly constant.»

— автор, стр. 146 наблюдение

Как выглядит признак

При неснижаемой водонасыщенности точки нескольких интервалов идут вдоль одной гиперболы или параллельно ей. Гипербола здесь соединяет точки равного объёмного содержания воды. Вне этого состояния точки рассеиваются относительно согласованного рисунка. Если точки рассеиваются, применимость оценки проницаемости не подтверждена. стр. 146

«On the chart, data points from different intervals in a zone at irreducible saturation plot in a coherent pattern, on or parallel to one of the hyperbolic curves.»

— автор, стр. 146 наблюдение

«Data points from zones not at $S_{wi}$ in scatter from this pattern.»

— автор, стр. 146 наблюдение

По шагам

Проверить рисунок точек

  1. Нанесите данные нескольких интервалов одной зоны. стр. 146
  2. Сравните распределение точек с гиперболами. стр. 146
  3. Оценивайте проницаемость только при неснижаемой водонасыщенности. стр. 146

Потренируйтесь

Дано: Точки лежат вдоль одной гиперболы или параллельно ей. (модель)

Такой согласованный рисунок описан для неснижаемого состояния.

Дано: Точки рассеиваются относительно согласованного рисунка. (модель)

Рассеяние характерно для зоны вне требуемого состояния.

Цифры и условия

  • Оценка проницаемости по палетке действительна только при неснижаемой водонасыщенности. стр. 146
  • Почти постоянное содержание воды проявляется согласованным рисунком нескольких точек. стр. 146

Частая ошибка по книге

✗ Ошибка: Палетка даёт действительную оценку проницаемости для любой водонасыщенности.

✓ На самом деле: Для оценки проницаемости палетка действительна только при неснижаемой водонасыщенности. стр. 146

Что это значит для данных по книге

Новые понятия

Неснижаемая водонасыщенность (irreducible water saturation)
Водонасыщенность, при которой в рассматриваемом пласте вода не вытесняется при добыче. стр. 146 модель
Объёмное содержание воды (bulk volume water)
Доля объёма породы, занятая водой; на палетке равно произведению неснижаемой водонасыщенности на пористость. стр. 146
Проницаемость (permeability)
Способность породы пропускать флюид через поры. стр. 146 модель
Палетка (chart)
График для определения величин по пересечению известных координат. стр. 146 модель
