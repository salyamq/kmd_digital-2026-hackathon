Когда метод отношений даёт меньше

В книге: «Ratio Method» стр. 126–128

≈ 4 мин ◆ Решение на данных трудность: неочевидное + интерпретация

Опирается на: шаг 15 «Что значит совпадение двух оценок» (предпосылка), шаг 10 «Как оценить воду у ствола» (предпосылка)

Суть

Если оценка Арчи выше, ищите причину заниженного отношения сопротивлений.

У этого расхождения больше одного возможного объяснения.

Пороговая идея. Знак расхождения подсказывает, где искать проблему в сопротивлениях. модель

Как это работает

Механизм

Если оценка Арчи выше, автор считает отношение мелкого сопротивления к истинному заниженным. При очень мелком проникновении мелкое сопротивление может быть занижено. При очень глубоком проникновении истинное сопротивление может быть завышено. стр. 128

«2. If $S_{wa} > S_{wr}$, then the value for $R_{xo}/R_t$ is too low.»

— автор, стр. 128 вывод

«$R_{xo}$ is too low because invasion is very shallow, or $R_t$ is too high because invasion is very deep.»

— автор, стр. 128 вывод

Ограничение

Переходный профиль — постепенная смена промытой части незатронутой. Автор допускает этот профиль при таком расхождении. Он считает оценку Арчи хорошим приближением фактической доли воды. стр. 128

«Also, a transition-type invasion profile might be indicated and $S_{wa}$ is considered a good value for the zone's actual water saturation.»

— автор, стр. 128 вывод

  • Низкое отношение сопротивлений

Правило

Различите занижение мелкого и завышение истинного сопротивления. стр. 128

↓
Вывод

Рассмотрите также переходный профиль; автор считает оценку Арчи хорошим приближением.

Потренируйтесь

Дано: Арчи даёт больше воды, а независимые признаки глубины проникновения ещё не проверены. (модель)

Знак разности не различает две причины.

Цифры и условия

  • Рассматриваемый признак относится к случаю, когда оценка Арчи выше оценки методом отношений. стр. 128

Новые понятия

Водонасыщенность (water saturation)
Доля порового пространства, заполненная водой. модель
Мелкое сопротивление (shallow resistivity)
Сопротивление, измеренное прибором, исследующим область непосредственно у ствола. стр. 127
Истинное сопротивление пласта (true formation resistivity)
Значение по глубинному индукционному или глубинному боковому каротажу после поправки на проникновение. стр. 126
Проникновение (invasion)
Вторжение фильтрата бурового раствора в пласт. модель
Переходный профиль (transition-type invasion profile)
Плавный переход между промытой и незатронутой частями пласта. модель

Источник

Все утверждения шага с дословной цитатой автора и страницей книги (по PDF).

  1. Если оценка Арчи выше, отношение мелкого сопротивления к истинному занижено. вывод

    «2. If $S_{wa} > S_{wr}$, then the value for $R_{xo}/R_t$ is too low.»

    — стр. 128

  2. При мелком проникновении мелкое сопротивление может оказаться заниженным; при глубоком — истинное сопротивление завышенным. вывод

    «$R_{xo}$ is too low because invasion is very shallow, or $R_t$ is too high because invasion is very deep.»

    — стр. 128

  3. Возможен переходный профиль; оценку Арчи принимают как хорошую оценку фактической водонасыщенности. вывод

    «Also, a transition-type invasion profile might be indicated and $S_{wa}$ is considered a good value for the zone's actual water saturation.»

    — стр. 128
Исходный текст урока

Стр. 128 · Ratio Method

2. If $S_{wa} > S_{wr}$, then the value for $R_{xo}/R_t$ is too low. $R_{xo}$ is too low because invasion is very shallow, or $R_t$ is too high because invasion is very deep. Also, a transition-type invasion profile might be indicated and $S_{wa}$ is considered a good value for the zone's actual water saturation.
