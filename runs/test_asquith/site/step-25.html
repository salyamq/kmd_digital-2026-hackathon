Как получить пористость по сопротивлению

В книге: «Conductivity-derived porosity» стр. 129–130

≈ 6 мин ◆ Решение на данных трудность: интерпретация + процесс/прибор

Опирается на: шаг 18 «Что даёт быстрая оценка» (предпосылка), шаг 20 «Две кривые на одной дорожке» (предпосылка), шаг 8 «Как оценить воду вдали от ствола» (предпосылка)

Суть

Сначала рассчитайте пористость для случая, будто поры заполнены только водой.

Затем сравните её значения в пористых и проницаемых интервалах.

Пороговая идея. Расчётная пористость под водяной гипотезой — диагностический признак, а не независимое измерение. модель

Как это работает

Механизм

Первоначально метод использовал кривую проводимости — отклика, связанного с прохождением тока. Её теперь редко показывают. Авторы используют сопротивление незатронутой зоны в уравнении Арчи. В расчёт подставляют водонасыщенность 1,0: поры считают полностью заполненными водой. стр. 130

«Although this technique originated with the use of the conductivity curve (Dresser Atlas, 1975), the conductivity curve is now rarely presented on log displays, and the technique is described here using the resistivity measurement.»

— автор, стр. 130 наблюдение

«This technique calculates a porosity from Archie's equation, using the form of the equation for water-bearing zones ($S_w = 1$).»

— автор, стр. 130 допущение

«1. Calculate the porosity from Archie's equation (assuming $S_w = 1.0$), using the uninvaded zone resistivity measurement.»

— автор, стр. 130 наблюдение

Практика

На дорожке ПС большие значения откладывают слева, малые — справа. Положение и значения кривой сравнивают в пористых проницаемых зонах. Для оценки водонасыщенности её можно сравнить с акустической, плотностной или нейтронной пористостью. стр. 130

«The porosity values are generated as a curve and are normally displayed in the same track as the SP, scaled from high porosity values on the left to low porosity values on the right.»

— автор, стр. 130 наблюдение

«2. Compare the curve values and the relative position of the curve in porous and permeable zones.»

— автор, стр. 130 наблюдение

«3. If desired, an Archie water saturation can be calculated by comparing the conductivity-derived porosity ty to porosity from one of the porosity measurements (sonic, density, or neutron).»

— автор, стр. 130 наблюдение

По шагам

По шагам

  1. Рассчитайте пористость по сопротивлению незатронутой зоны при водонасыщенности 1,0. стр. 130
  2. Сопоставьте значения кривой между пористыми проницаемыми зонами. стр. 130
  3. При необходимости сравните расчёт с отдельной кривой пористости. стр. 130

Правило

Вывод

При необходимости сравните с независимой кривой, чтобы оценить водонасыщенность.

Потренируйтесь

Дано: Есть сопротивление незатронутой зоны и пригодные интервалы. (модель)

Метод использует водоносную форму уравнения Арчи.

Дано: Нужна оценка насыщенности; есть плотностная пористость. (модель)

Авторы используют сравнение с отдельной кривой для оценки насыщенности.

Цифры и условия

  • В расчёт подставляют водонасыщенность 1,0: поры считают полностью заполненными водой. стр. 130
  • Сравнивают пористые и проницаемые зоны. стр. 130

Новые понятия

Пористость по сопротивлению (conductivity-derived porosity)
Расчётная пористость из уравнения Арчи при допущении полного насыщения водой. стр. 130
Истинное сопротивление (true formation resistivity)
Сопротивление незатронутой зоны пласта. модель
Водонасыщенность (water saturation)
Доля порового объёма, занятая водой. модель
Пористость (porosity)
Доля объёма породы, занятая порами. модель
Проницаемость (permeability)
Способность породы пропускать флюид. модель
ПС (spontaneous potential)
Кривая самопроизвольной поляризации, отклик на различие сопротивлений пластовой воды и фильтрата. стр. 129
Электропроводность (conductivity)
Величина, обратная удельному электрическому сопротивлению. модель

Исходный текст урока

Стр. 130 · Conductivity-derived porosity (also referred to as resistivity-porosity)

Although this technique originated with the use of the conductivity curve (Dresser Atlas, 1975), the conductivity curve is now rarely presented on log displays, and the technique is described here using the resistivity measurement.

Стр. 130 · Conductivity-derived porosity (also referred to as resistivity-porosity)

This technique calculates a porosity from Archie's equation, using the form of the equation for water-bearing zones ($S_w = 1$). The porosity values are generated as a curve and are normally displayed in the same track as the SP, scaled from high porosity values on the left to low porosity values on the right.

Стр. 130 · Procedure

1. Calculate the porosity from Archie's equation (assuming $S_w = 1.0$), using the uninvaded zone resistivity measurement.

Стр. 130 · Procedure

2. Compare the curve values and the relative position of the curve in porous and permeable zones.

Стр. 130 · Procedure

3. If desired, an Archie water saturation can be calculated by comparing the conductivity-derived porosity ty to porosity from one of the porosity measurements (sonic, density, or neutron).
