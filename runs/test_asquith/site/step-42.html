Как провести линию равной насыщенности

В книге: «Диаграмма Пикетта» стр. 142

≈ 5 мин ◆ Решение на данных трудность: процесс/прибор + формализм

Опирается на: шаг 40 «Как выбрать водоносную линию Пикетта» (предпосылка), шаг 41 «Как найти сопротивление пластовой воды» (предпосылка), шаг 38 «Как нанести линии на Пикетта» (пример)

Суть

На Пикетте линию водонасыщенности проводят параллельно водоносной.

Табличный множитель даёт сопротивление опорной точки при той же пористости.

Пороговая идея. На диаграмме Пикетта линии заданной насыщенности параллельны водоносной линии. модель

Как это работает

Как получить опорную точку

Возьмите сопротивление водоносной линии, линии полного водонасыщения, при фиксированной пористости. Умножьте его на табличный множитель, коэффициент для выбранной водонасыщенности. Табличные множители применяют при показателе насыщения $n=2{,}0$. Через найденную точку проведите линию параллельно водоносной. стр. 142

«The water saturation lines are constructed on the plot from the value for $R_{a}$ and the multipliers from Table 7.2.»

— автор, стр. 142 вывод

«The multipliers are for a saturation exponent ($n$) of 2.0.»

— автор, стр. 142 допущение

«For each line to be plotted, multiply $R_{a}$ by the multiplier to get the $y$-intercept and draw a line from the $y$-intercept parallel to the water-bearing line.»

— автор, стр. 142 вывод

Линия для половины объёма пор

В примере строят линию водонасыщенности 50%. При плотностной пористости DPHI = 0,10 сопротивление водоносной линии равно 4,6, а табличный множитель равен 4. Умножение даёт 18,4 при той же пористости. стр. 142

«To plot the line for $50\%$ water saturation, for example, if $R_{a}$ (at $\mathrm{DPHI} = 0.10$) is 4.6 and the multiplier (from Table 7.2) is 4, the $y$-intercept for the $50\%$ water saturation line (at $\mathrm{DPHI} = 0.10$) is 18.4.»

— автор, стр. 142 наблюдение

По шагам

По шагам

  1. Считайте сопротивление водоносной линии при выбранной пористости. стр. 142
  2. Умножьте сопротивление на множитель для выбранной водонасыщенности. стр. 142
  3. Проведите линию через найденную точку параллельно водоносной. стр. 142

Разбор примеров из книги по книге

Линия водонасыщенности 50% стр. 142

Условие. При DPHI = 0.10 R_a = 4.6; множитель из таблицы 7.2 равен 4.

  1. Умножить 4.6 на 4.
  2. Найти точку при DPHI = 0.10 и сопротивлении 18.4.
  3. Провести линию параллельно водоносной.

Итог. Опорное значение для линии 50% равно 18.4.

Решение на данных

Как построить линию для 50%

Признаки
  • Плотностная пористость 0,10
  • Опорное сопротивление 4,6
  • Табличный множитель 4
↓
Правило

Умножьте сопротивление на множитель и сохраните прежнюю пористость. стр. 142

↓
Вывод

Через точку с сопротивлением 18,4 проведите параллель к водоносной линии.

Потренируйтесь

Дано: Искомая линия соответствует 50% воды. При пористости 0,10 опора равна 4,6, показатель насыщения равен 2,0. (модель: условие из узла)

Множитель 4 относится к сопротивлению, а пористость не меняется.

Цифры и условия

  • Табличные множители применяют при показателе насыщения $n=2{,}0$. стр. 142
  • При DPHI = 0,10 для линии 50% исходное сопротивление 4,6 умножают на 4 и получают 18,4. стр. 142

Что это значит для данных по книге

Параллельные линии вычислены по опорной, а не подгоняются по отдельным группам точек.

Вход
Водоносная линия и множители.
Выход

Ручные шаги

Точки суждения
Проверить, что показатель насыщения соответствует таблице.

Сопротивление водоносной породы (resistivity in the undisturbed, water-bearing zone)

Водоносная линия (water-bearing line)
Линия, проведённая через группу точек пласта, насыщенного водой. стр. 142

Исходный текст урока

Стр. 142 · **Carbonates:**

The water saturation lines are constructed on the plot from the value for $R_{a}$ and the multipliers from Table 7.2. The multipliers are for a saturation exponent ($n$) of 2.0. For each line to be plotted, multiply $R_{a}$ by the multiplier to get the $y$-intercept and draw a line from the $y$-intercept parallel to the water-bearing line. To plot the line for $50\%$ water saturation, for example, if $R_{a}$ (at $\mathrm{DPHI} = 0.10$) is 4.6 and the multiplier (from Table 7.2) is 4, the $y$-intercept for the $50\%$ water saturation line (at $\mathrm{DPHI} = 0.10$) is 18.4.
