Как уточнить насыщенность на Хингле

В книге: «Диаграмма Хингла» стр. 145

≈ 6 мин ◆ Решение на данных трудность: формализм + процесс/прибор

Опирается на: шаг 52 «Как провести линию водонасыщенности» (предпосылка), шаг 43 «Как посчитать насыщенность по Пикетту» (пример)

Суть

Для более точной оценки водонасыщенности используйте формулу, а не чтение графика на глаз.

Важный шаг — найти сопротивление водоносной линии на уровне пористости изучаемой точки.

Пороговая идея. Сравнивают сопротивления при одинаковой пористости, а не произвольные точки графика. модель

Как это работает

От графика к расчёту

Водонасыщенность — доля пор, занятая водой. На Хингле можно оценить её по положению точки. Для большей точности авторы рекомендуют формулу. Опорное сопротивление считывают при той же пористости, что и у изучаемой точки. стр. 145

«To determine the water saturation of the anomalous points (with more accuracy than estimating the values from the crossplot), the following equation can be used:»

— автор, стр. 145 вывод

«In this case, the value for R_a is the value at the water-bearing line at the same porosity as the point of interest.»

— автор, стр. 145 вывод

Что подставить

Разделите сопротивление водоносной линии на сопротивление точки. Возведите отношение в степень 1/n. Показатель насыщения n задаёт степень через обратную величину. В примере у двух точек одна пористость, и им соответствует одна опора 0,83 Ом·м. стр. 145

«For the two points of interest (both having the same porosity), R_a = 0.83 ohm-m.»

— автор, стр. 145 наблюдение

«For the point who's resistivity is 40 ohm-m, the saturation is found by:»

— автор, стр. 145 наблюдение

Пример и сравнение

Для точки 40 Ом·м при n = 2,0 авторы получают водонасыщенность 0,144. Для сопоставления авторы показывают тот же набор данных на диаграмме Пикетта, другом графике сопротивления и пористости. стр. 145

«For comparison of interpretation, Figure 7.4 is a Pickett plot with the same data shown.»

— автор, стр. 145 наблюдение

По шагам

Посчитать насыщенность точки

  1. Определите пористость изучаемой точки. стр. 145
  2. Считайте сопротивление водоносной линии при той же пористости. стр. 145
  3. Подставьте опорное сопротивление, сопротивление точки и показатель насыщения. стр. 145

Разбор примеров из книги по книге

Водонасыщенность по формуле стр. 145

Условие. Сопротивление точки 40 Ом·м и показатель насыщения 2.0.

  1. Считать 0.83 Ом·м с водоносной линии при пористости этой точки.
  2. Подставить отношение 0.83/40 и показатель 2.0.

Итог. S_w = 0.144.

Решение на данных

Проверить пару сопротивлений

Признаки
  • Пористость точки
  • Сопротивление изучаемой точки
  • Сопротивление водоносной линии
↓
Правило

Сопоставьте сопротивления при одной пористости, затем примените формулу. стр. 145

↓
Вывод

Получите расчётную водонасыщенность изучаемой точки.

Потренируйтесь

Дано: У двух точек та же пористость, опора 0,83 Ом·м. (Пример 1, стр. 145)

Опора определяется пористостью.

Дано: Точка 40 Ом·м, опора 0,83 Ом·м и n = 2,0. (Пример 1, стр. 145)

0,83 Ом·м — сопротивление, а не доля воды.

Цифры и условия

  • Для двух точек одной пористости опорное сопротивление равно 0,83 Ом·м. стр. 145
  • Для точки 40 Ом·м при n = 2,0 результат равен 0,144. стр. 145
  • Для расчёта не подходят опоры при другой пористости. стр. 145

Формулы по книге

$$S_w=\left(\frac{R_a}{R_s}\right)^{1/n}$$

Что это значит для данных по книге

Опорное и измеренное сопротивления сопоставимы на одной пористости.

Вход
Сопротивление точки и водоносной линии при равной пористости, показатель насыщения.
Выход
Расчётная водонасыщенность.
Где ломается
Опорная ордината должна соответствовать пористости точки.
Где здесь ручной труд специалиста
Входные данные
Координаты точки, водоносная линия, показатель насыщения.
Ручные шаги
Считать опорную ординату и вычислить насыщенность.
Точки суждения
Установить соответствие по пористости.
Время
Больше действий, чем при чтении ближайшей линии.
Типичные ошибки
Сравнить точки при разных пористостях.

Новые понятия

Сопротивление водоносной линии (water-bearing line resistivity)
Сопротивление, считанное с линии водоносных точек при заданной пористости. стр. 145
Диаграмма Хингла (Hingle plot)
Диаграмма для совместной интерпретации сопротивления и пористости или её показателя. стр. 145 модель
Пористость (porosity)
Доля объёма пор в породе. стр. 145 модель
Водонасыщенность (water saturation)
Доля объёма пор, занятая водой. стр. 145 модель
Показатель насыщения (saturation exponent)
Степенной параметр n в формуле водонасыщенности. стр. 145 модель
Диаграмма Пикетта (Pickett plot)
Другая диаграмма связи сопротивления и пористости; здесь на ней показаны те же данные. стр. 145

Исходный текст урока

Стр. 145 · **Carbonates:**

To determine the water saturation of the anomalous points (with more accuracy than estimating the values from the crossplot), the following equation can be used:

Стр. 145 · **Carbonates:**

$$S_w = \left(\frac{R_a}{R_s}\right)^{\frac{1}{n}}$$

Стр. 145 · **Carbonates:**

In this case, the value for R_a is the value at the water-bearing line at the same porosity as the point of interest. For the two points of interest (both having the same porosity), R_a = 0.83 ohm-m. For the point who's resistivity is 40 ohm-m, the saturation is found by:

Стр. 145 · **Carbonates:**

$$S_w = \left(\frac{0.83}{40}\right)^{\frac{1}{2.0}}$$

Стр. 145 · **Carbonates:**

$$S_w = 0.144$$

Стр. 145 · **Carbonates:**

For comparison of interpretation, Figure 7.4 is a Pickett plot with the same data shown.
