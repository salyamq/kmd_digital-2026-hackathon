Как провести линию водонасыщенности

В книге: «Диаграмма Хингла» стр. 145

≈ 6 мин ◆ Решение на данных трудность: процесс/прибор + формализм

Опирается на: шаг 51 «Как найти сопротивление пластовой воды» (предпосылка), шаг 48 «Как провести веер насыщения» (пример)

Суть

На диаграмме Хингла линия заданной водонасыщенности проходит через две опоры.

Одну точку получают по множителю, другая лежит на водоносной линии при бесконечном сопротивлении.

Пороговая идея. На диаграмме Хингла линии насыщенности сходятся к водоносной линии при бесконечном сопротивлении. модель

Как это работает

Что задаёт построение

Диаграмма Хингла сопоставляет сопротивление и пористость или её показатель. Водонасыщенность — доля пор, занятая водой. Авторы берут сопротивление водоносной линии и множители из таблицы 7.2. Множители рассчитаны для показателя насыщения n = 2,0, степенного параметра уравнения. стр. 145

«The water saturation lines are constructed on the plot from the value for R_a and the multipliers from Table 7.2.»

— автор, стр. 145 вывод

«The multipliers are for a saturation exponent (n) of 2.0.»

— автор, стр. 145 допущение

Построение по двум опорам

Считайте опору при выбранной плотности. Умножьте её на табличный множитель. Соедините найденную точку с водоносной линией при бесконечном сопротивлении. На этапе умножения сохраняйте ту же объёмную плотность, учитывающую породу и содержимое пор. стр. 145

«For each line to be plotted, multiply R_a by the multiplier and plot that line so that it intersects the water-bearing line at infinite resistivity.»

— автор, стр. 145 вывод

«In this example, R_a (at bulk density = 2.485 g/cm³) is 4.1. The intercept for the 50% water-saturation line (at bulk density = 2.485 g/cm³) is 16.4.»

— автор, стр. 145 наблюдение

Линия из примера

При плотности 2,485 г/см³ сопротивление опоры равно 4,1. Точка линии 50% при той же плотности соответствует сопротивлению 16,4. стр. 145

По шагам

Провести линию

  1. Считайте сопротивление водоносной линии при фиксированной плотности. стр. 145
  2. Умножьте на множитель и нанесите полученную точку при той же плотности. стр. 145
  3. Проведите линию через эту точку и пересечение с водоносной линией при бесконечном сопротивлении. стр. 145

Разбор примеров из книги по книге

Линия насыщенности 50% стр. 145

Условие. Объёмная плотность 2.485 г/см³; у множителей n = 2.0.

  1. Взять опорное сопротивление 4.1.
  2. По множителю получить значение 16.4 при той же плотности.
  3. Провести линию через отмеченную точку и пересечение с водоносной линией при бесконечном сопротивлении.

Итог. Получена линия водонасыщенности 50%.

Решение на данных

Проверить две опоры

Признаки
  • Объёмная плотность
  • Сопротивление водоносной линии
  • Множитель для выбранной водонасыщенности
↓
Правило

Умножение выполняют при той же плотности, а вторую опору берут при бесконечном сопротивлении. стр. 145

↓
Вывод

Две опоры задают линию выбранной водонасыщенности.

Потренируйтесь

Дано: При плотности 2,485 г/см³ опорное сопротивление 4,1. Нужна линия 50%. (Пример 1, стр. 145)

Умножение меняет сопротивление, а не плотность.

Дано: Точку линии уже нанесли, нужно выбрать вторую опору. (Пример 1, стр. 145)

Автор задаёт место пересечения при бесконечном сопротивлении.

Цифры и условия

  • Множители таблицы относятся к n = 2,0. стр. 145
  • При плотности 2,485 г/см³ опоре 4,1 соответствует точка 16,4 для линии 50%. стр. 145
  • Общее пересечение линий находится при бесконечном сопротивлении. стр. 145

Что это значит для данных по книге

Линия — результат построения, а не отдельное измерение.

Вход
Водоносная линия, плотность и множители таблицы 7.2.
Выход
Линии заданной водонасыщенности.
Где ломается
Табличные множители относятся к указанному показателю насыщения.
Где здесь ручной труд специалиста
Входные данные
Сетка Хингла и множители.
Ручные шаги
Рассчитать точки и провести линии.
Точки суждения
Проверить показатель насыщения, использованный для таблицы.
Время
Повторяющиеся действия для каждой линии.
Типичные ошибки
Соединить линию с водоносной в точке конечного сопротивления.

Аналогия модель

Похоже на построение изолиний по опорным точкам.

Где аналогия перестаёт работать: Опоры задаёт физическая модель и специальная шкала, а не произвольный графический шаблон.

Новые понятия

Сопротивление водоносной линии (water-bearing line resistivity)
Сопротивление, считанное с линии водоносных точек при заданной пористости. стр. 145
Объёмная плотность (bulk density)
Масса породы и содержимого её пор на единицу общего объёма. стр. 145 модель
Диаграмма Хингла (Hingle plot)
Диаграмма для совместной интерпретации сопротивления и пористости или её показателя. стр. 145 модель
Водонасыщенность (water saturation)
Доля объёма пор, занятая водой. стр. 145 модель
Показатель насыщения (saturation exponent)
Степенной параметр n в формуле водонасыщенности. стр. 145 модель
