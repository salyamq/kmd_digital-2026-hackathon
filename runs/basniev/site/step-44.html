Зачем нужны приближённые методы

В книге: «Приближенные методы решения задач теории упругого режима» стр. 494

≈ 4 мин ¶ Текст трудность: формализм + неочевидное

Опирается на: шаг 13 «Как работает уравнение пьезопроводности» (предпосылка), шаг 36 «Основная формула упругого режима» (предпосылка), шаг 41 «Проверить влияние внешней границы» (предпосылка)

Суть

Точные решения задач упругого режима существуют, но часто слишком громоздки для расчётов.

Поэтому автор переходит к приближённым методам, которые широко применяют на практике.

Пороговая идея. Точное решение уравнения может быть неудобным для практических вычислений. модель

Как это работает

Откуда берутся точные решения

Неустановившуюся фильтрацию описывает уравнение пьезопроводности (уравнение изменения давления в пласте). Краевые задачи для бесконечного пласта решают его интегрированием. Для конечного пласта используют те же методы интегрирования. стр. 494

«Как было показано в предыдущей главе, решения краевых задач неустановившейся фильтрации упругой жидкости в упругой пористой среде в условиях как бесконечного, так и конечного пластов можно получить при помощи хорошо известных методов интегрирования дифференциального уравнения пьезопроводности (теплопроводности) (23.16).»

— автор, стр. 494 наблюдение

«Как было показано в предыдущей главе, решения краевых задач неустановившейся фильтрации упругой жидкости в упругой пористой среде в условиях как бесконечного, так и конечного пластов можно получить при помощи хорошо известных методов интегрирования дифференциального уравнения пьезопроводности (теплопроводности) (23.16).»

— автор, стр. 494 наблюдение

Автор сопоставляет уравнение пьезопроводности с уравнением теплопроводности. Поэтому для давления годятся хорошо известные методы теории теплопроводности. стр. 494

— автор, стр. 494 наблюдение

В чём проблема

Точные решения часто громоздки. Первая форма — бесконечный медленно сходящийся ряд: сумму приходится считать по многим членам. Вторая форма — несобственный интеграл со специальными функциями, то есть интеграл через предел. стр. 494

«Однако во многих случаях эти решения представляются громоздкими формулами в виде бесконечного медленно сходящегося ряда или несобственного интеграла, содержащего специальные функции.»

— автор, стр. 494 наблюдение

«Однако во многих случаях эти решения представляются громоздкими формулами в виде бесконечного медленно сходящегося ряда или несобственного интеграла, содержащего специальные функции.»

— автор, стр. 494 наблюдение

Что делает специалист

Громоздкость точных формул, по выводу автора, побудила искать эффективные приближённые решения. Далее автор рассматривает несколько таких методов. Они широко применяются для задач упругого режима. стр. 494

«В связи с этим были предприняты поиски приближенных эффективных решений задач неустановившейся фильтрации упругой жидкости в упругой пористой среде.»

— автор, стр. 494 вывод

«Рассмотрим здесь некоторые из разработанных приближенных методов, получивших широкое применение при решении задач теории упругого режима.»

— автор, стр. 494 наблюдение

Нюанс

Приближения нужны не потому, что точных решений нет. Они нужны потому, что точные выражения неудобны для вычислений. стр. 494

Пояснение

Сравните с картой и навигатором. Точная карта есть, но для поездки удобнее простой маршрут. Приближённый метод играет роль такого маршрута. пояснение модели

Что это значит для данных по книге

Для таких задач автор переходит к эффективным приближённым методам, применяемым в теории упругого режима.

Вход
Краевая задача для упругой жидкости в упругой пористой среде.
Выход
Точное решение или постановка задачи для приближённого метода.
Где ломается
В этом вводном абзаце ещё не указаны условия точности конкретного приближения.
Где здесь ручной труд специалиста
Входные данные
Краевая задача для упругой жидкости в упругой пористой среде.
Ручные шаги
Сопоставить сложность вычисления точного выражения с доступными приближениями.
Точки суждения
При выборе приближения отдельно проверять условия и требуемую точность.
Время
Вычислительная трудоёмкость зависит от вида точного решения.
Типичные ошибки
Считать, что приближённые методы вводятся потому, что точное уравнение невозможно решить.

Новые понятия

Краевая задача
Уравнение вместе с условиями на границах и, для неустановившегося процесса, с начальным состоянием. стр. 494 модель
Пьезопроводность
Здесь распространение изменений давления, описанное уравнением, подобным уравнению теплопроводности. стр. 494 модель
Несобственный интеграл
Интеграл, определяемый через предел, например при бесконечной границе интегрирования. стр. 494 модель
Медленно сходящийся ряд
Бесконечная сумма, которую приходится вычислять по многим членам, чтобы приблизиться к её значению. стр. 494 модель
Упругая пористая среда
Проницаемая для жидкости порода, деформирующаяся при изменении давления. стр. 494 модель
