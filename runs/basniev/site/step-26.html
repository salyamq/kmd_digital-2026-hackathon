Шаблон решения для скорости

В книге: «Прямолинейно-параллельный фильтрационный поток упругой жидкости» стр. 486

≈ 7 мин ¶ Текст трудность: формализм

Опирается на: шаг 25 «Уравнение для скорости фильтрации» (предпосылка), шаг 21 «От интеграла к давлению в пласте» (предпосылка)

Суть

Решение для скорости ищут в том же виде, что для давления: функция ошибок с двумя постоянными.

Начальное условие даёт связь: сумма постоянных равна нулю.

Каждую постоянную по отдельности найдут из условия на галерее.

Как это работает

Форма решения

Уравнение для скорости по форме совпадает с уравнением теплопроводности. стр. 486

«Уравнение (23.33) по форме также совпадает с уравнением теплопроводности (23.22).»

— автор, стр. 486 наблюдение

Поэтому берут решение того же типа, что для давления. стр. 486

«Следовательно, решением уравнения (23.33) будет решение, аналогичное (23.26), с заменой давления $p$ на скорость фильтрации $w$»

— автор, стр. 486 вывод

Шаблон скорости — функция ошибок с множителем C1 и постоянным смещением C2. стр. 486

«$$w = C_1 \operatorname{erf} \left( \frac{x}{2\sqrt{\kappa t}} \right) + C_2. \quad (23.34)$$»

— автор, стр. 486 вывод

Условия

До пуска скорость фильтрации равна нулю. Это начальное условие. стр. 486

«$$w(x, 0) = 0, \quad w(0, t) = w_1.$$»

— автор, стр. 486 допущение

На галерее скорость равна заданному ненулевому значению при отборе. Это граничное условие. стр. 486

«$$w(x, 0) = 0, \quad w(0, t) = w_1.$$»

— автор, стр. 486 допущение

Обе постоянные определяют из этих двух условий. стр. 486

«Используя эти условия, найдем константы интегрирования.»

— автор, стр. 486 вывод

Применение начального условия

При нулевом времени верхний предел интеграла становится бесконечным. Скорость при этом равна нулю. стр. 486

«$$0 = C_1 \frac{2}{\sqrt{\pi}} \int_0^\infty e^{-u^2} du + C_2.$$»

— автор, стр. 486 вывод

Делить на нуль нельзя. Поэтому для точки внутри пласта берут предел при времени, стремящемся к нулю. стр. 486

Полный интеграл от нуля до бесконечности равен половине корня из пи. стр. 486

«Так как $\int_0^\infty e^{-u^2} du = \sqrt{\pi}/2$, получаем»

— автор, стр. 486 наблюдение

После подстановки сумма постоянных равна нулю. стр. 486

«$$0 = C_1 + C_2.$$»

— автор, стр. 486 вывод

Одного начального условия хватает только для связи постоянных. Чтобы найти каждую, нужно условие на галерее. стр. 486

  1. Возьмите шаблон с функцией ошибок. стр. 486

Что это значит для данных по книге

Один аналитический шаблон подходит для вычисления другой физической величины при её собственных условиях.

Выход

Типичные ошибки
Перенести старые постоянные вместе с функцией ошибок.

Аналогия модель

Похоже на повторное использование параметризованной функции с новыми граничными параметрами.

Где аналогия перестаёт работать: Одинаковая форма не делает давление и скорость одинаковыми по единицам.

Глубже

Берём форму, а не значения модель

Профиль скорости должен убывать от галереи в пласт. Знакомая функция ошибок сама растёт, поэтому множитель при ней в этом режиме получится отрицательным.

Как понимать подстановку нулевого времени модель

Нельзя делить на нуль в автомодельном аргументе. Для фиксированной точки с положительной координатой сначала берут предел при времени, стремящемся к нулю справа.
