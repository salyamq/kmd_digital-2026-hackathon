Один аргумент вместо трёх

В книге: «Прямолинейно-параллельный фильтрационный поток упругой жидкости» стр. 482

≈ 6 мин ¶ Текст трудность: формализм

Опирается на: шаг 16 «Три условия для давления» (предпосылка), шаг 13 «Как работает уравнение пьезопроводности» (предпосылка)

Суть

Из соображений размерности расстояние, время и пьезопроводность сводят к одной безразмерной координате.

Тогда все профили давления в разные моменты описывает одна функция.

Уравнение пьезопроводности сохраняет свой вид.

Пороговая идея. Разные профили давления становятся одной кривой, если изменить шкалу расстояния. модель

Как это работает

Нормировка давления

Давление нормируют. Берут превышение над давлением галереи и делят на начальный перепад. Получается безразмерная величина — без единиц измерения. стр. 482

«Обозначим через $P = (p - p_\tau)/(p_\kappa - p_\tau)$ безразмерное давление»

— автор, стр. 482 наблюдение

До упрощения безразмерное давление — функция трёх аргументов. Это расстояние, время и пьезопроводность. стр. 482

«$$P = f(x, t, \kappa).$$»

— автор, стр. 482 вывод

Анализ размерностей

Координата имеет размерность длины. Время — времени. Пьезопроводность — площади, делённой на время. стр. 482

«Размерности этих аргументов следующие: $[x] = L$, $[t] = T$, $[\kappa] = L^2 T^{-1}$, и из них можно составить безразмерный комплекс $x/\sqrt{\kappa t}$.»

— автор, стр. 482 наблюдение

По выводу автора, анализ размерностей показывает: задача допускает один безразмерный аргумент. стр. 482

«Используя анализ размерностей, покажем, что поставленная задача автомодельна, т. е. из аргументов, от которых зависит давление, можно составить один безразмерный комплекс, от которого будет зависеть искомая функция $p(x, t)$.»

— автор, стр. 482 вывод

Чтобы получить величину без единиц, длину делят на корень из произведения пьезопроводности и времени. стр. 482

«Размерности этих аргументов следующие: $[x] = L$, $[t] = T$, $[\kappa] = L^2 T^{-1}$, и из них можно составить безразмерный комплекс $x/\sqrt{\kappa t}$.»

— автор, стр. 482 вывод

В автомодельной переменной u в знаменателе стоит удвоенный масштаб длины. Давление становится функцией только u. стр. 482

«Приняв за новую переменную безразмерную величину $u = x/(2\sqrt{\kappa t})$, сведем задачу к нахождению безразмерного давления $P$, зависящего только от $u$ (автомодельной переменной), $P = f(u)$.»

— автор, стр. 482 вывод

Новые условия и уравнение

На галерее безразмерное давление равно нулю. Вдали от галереи оно стремится к единице. стр. 482

«$$P = 0 \quad \text{при} \quad u = 0,$$»

— автор, стр. 482 допущение

«$$P = 1 \quad \text{при} \quad u = \infty. \tag{23.21}$$»

— автор, стр. 482 допущение

Уравнение линейно. Поэтому нормировка сохраняет его форму. стр. 482

«В силу линейности дифференциального уравнения (23.19) для безразмерного давления $P$ имеем такое же уравнение, как и для размерного $p$,»

— автор, стр. 482 вывод

Для безразмерного давления производная по времени снова равна пьезопроводности, умноженной на вторую производную по координате. стр. 482

«$$\frac{\partial P}{\partial t} = \kappa \frac{\partial^2 P}{\partial x^2}. \tag{23.22}$$»

— автор, стр. 482 вывод

Что это значит для данных модель

Вместо трёх независимых полей аргументов для профиля нужен один безразмерный аргумент.

Вход
Координата, время, коэффициент пьезопроводности, давления.
Выход
Безразмерные координата и давление.
Где ломается
Нормировка не определена при нулевом перепаде.
  • гипотеза Для соответствующего режима нормированные профили измерений могут совпасть в пределах погрешности.
Где здесь ручной труд специалиста
Входные данные
Координата, время, коэффициент пьезопроводности, давления.
Ручные шаги
Согласовать единицы, нормировать координаты и давления.
Точки суждения
Проверить, не близок ли перепад к нулю.
Время
Ручные пересчёты повторяются для каждого профиля.
Типичные ошибки
Вычислять корень только из времени без пьезопроводности.

Глубже

Проверка нормировки модель

Квадратный корень из произведения пьезопроводности и времени имеет единицы длины. Нулевой перепад исключён: с ним знаменатель нормировки обращается в нуль.

Проверка по исходным значениям модель

В числителе нормировки на галерее давления вычитаются до нуля; вдали числитель равен знаменателю. Постоянное смещение исчезает при дифференцировании.

Автомодельная переменная (similarity variable)

Величина без физических единиц: при составлении отношения соответствующие размерности сокращаются. модель
