Как вычислить функцию Ei рядом

В книге: «Плоскорадиальный фильтрационный поток упругой жидкости. Основная формула теории упругого режима фильтрации» стр. 491

≈ 4 мин ¶ Текст трудность: формализм

Опирается на: шаг 36 «Основная формула упругого режима» (предпосылка)

Суть

Интегральную показательную функцию можно вычислить как логарифм, минус постоянная Эйлера, плюс степенной ряд.

Ряд сходится при любом положительном аргументе.

В подземной гидромеханике постоянную Эйлера принимают равной 0,5772.

Пороговая идея. Ряд представляет специальную функцию при любом положительном аргументе, а не только вблизи нуля. модель

Как это работает

Запись рядом

Интегральную показательную функцию можно записать в виде ряда. −Ei(−x) = ln(1/x) − γ + сумма членов (−1)^(n+1)·xⁿ/(n·n!). Это степенной ряд — сумма членов с растущими степенями x. стр. 491

«Интегральную показательную функцию можно представить в виде ряда»

— автор, стр. 491 наблюдение

Сходимость

Ряд сходится при всех положительных x, то есть при 0 < x < ∞. Сходимость значит: с каждым новым членом частичная сумма приближается к пределу. стр. 491

«который сходится при всех значениях $x$ ($0 < x < \infty$), $\gamma$ – постоянная Эйлера – иррациональное число, приближенное значение которого при вычислениях в подземной гидромеханике принимается равным 0,5772.»

— автор, стр. 491 наблюдение

Постоянная Эйлера

В формулу входит постоянная Эйлера γ. Это иррациональное число: его нельзя записать отношением целых чисел. стр. 491

«который сходится при всех значениях $x$ ($0 < x < \infty$), $\gamma$ – постоянная Эйлера – иррациональное число, приближенное значение которого при вычислениях в подземной гидромеханике принимается равным 0,5772.»

— автор, стр. 491 наблюдение

Практика

В расчётах подземной гидромеханики γ приближённо принимают равной 0,5772. Это значение и подставляют в формулу. стр. 491

«который сходится при всех значениях $x$ ($0 < x < \infty$), $\gamma$ – постоянная Эйлера – иррациональное число, приближенное значение которого при вычислениях в подземной гидромеханике принимается равным 0,5772.»

— автор, стр. 491 наблюдение

Нюанс

Ряд представляет функцию при любом положительном аргументе, а не только вблизи нуля. Утверждение о сходимости дано только для положительных x. стр. 491

По шагам

Как посчитать −Ei(−x) по ряду

  1. Вычислите логарифм ln(1/x). стр. 491
  2. Вычтите постоянную Эйлера 0,5772. стр. 491
  3. Прибавьте сумму членов степенного ряда. стр. 491

Цифры и условия

  • Постоянную Эйлера в расчётах принимают равной 0,5772. стр. 491
  • Ряд сходится при 0 < x < ∞. стр. 491

Формулы по книге

$$- \text{Ei} (- x) = \ln \frac{1}{x} - \gamma + \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n \cdot n!} x^n,$$

Представление функции как логарифма, константы и степенного ряда. стр. 491

Что это значит для данных по книге

При вычислениях в подземной гидромеханике автор использует приближённое значение постоянной Эйлера.

Вход
Положительный безразмерный аргумент и постоянная Эйлера.
Выход
Значение интегральной показательной функции.
Где ломается
Утверждение о сходимости дано только для положительных аргументов.
Где здесь ручной труд специалиста
Входные данные
Положительный безразмерный аргумент и постоянная Эйлера.
Ручные шаги
Проверить область аргумента и сверить знак членов ряда.
Точки суждения
Отличить сходимость полного ряда от точности его усечения.
Время
Ручное суммирование требует времени и контроля остатка.
Типичные ошибки
Принять приближённую постоянную за её точное значение.
