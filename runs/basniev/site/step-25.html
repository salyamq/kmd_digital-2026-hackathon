Уравнение для скорости фильтрации

В книге: «Прямолинейно-параллельный фильтрационный поток упругой жидкости» стр. 485–486

≈ 5 мин ¶ Текст трудность: формализм + процесс/прибор

Опирается на: шаг 24 «Пуск галереи с постоянным дебитом» (предпосылка), шаг 13 «Как работает уравнение пьезопроводности» (предпосылка), шаг 9 «Из чего складывается модель течения» (предпосылка)

Суть

Из уравнения для давления получают такое же уравнение для скорости фильтрации.

Коэффициент пьезопроводности в нём тот же.

Как это работает

Вывод

Уравнение для давления умножают на отношение проницаемости к вязкости. стр. 485

«Для интегрирования уравнения пьезопроводности в данном случае умножим обе части уравнения (23.22) на $k/\mu$»

— автор, стр. 485 вывод

Затем дифференцируют по координате. Слева появляется смешанная производная, справа — третья производная давления по координате. стр. 486

«$$\frac{k}{\mu} \frac{\partial^2 p}{\partial x \partial t} = \frac{k}{\mu} \kappa \frac{\partial^3 p}{\partial x^3},$$»

— автор, стр. 486 вывод

Порядок производных переставляют. Тогда в обеих частях выделяется один и тот же градиентный множитель. стр. 486

«$$\frac{\partial}{\partial t} \left( \frac{k}{\mu} \frac{\partial p}{\partial x} \right) = \kappa \frac{\partial^2}{\partial x^2} \left( \frac{k}{\mu} \frac{\partial p}{\partial x} \right). \quad (23.32)$$»

— автор, стр. 486 вывод

По закону Дарси этот множитель — скорость фильтрации в принятом направлении. стр. 486

«$$\frac{k}{\mu} \frac{\partial p}{\partial x} = w(x, t),$$»

— автор, стр. 486 наблюдение

Результат

Уравнение для скорости имеет тот же диффузионный вид. Коэффициент пьезопроводности тот же. стр. 486

«$$\frac{\partial w(x, t)}{\partial t} = \kappa \frac{\partial^2 w(x, t)}{\partial x^2}. \quad (23.33)$$»

— автор, стр. 486 вывод

Коэффициенты выносят из производных как постоянные. Если свойства меняются в пространстве, такой вывод без проверки не годится. стр. 485

По шагам

Как получить уравнение для скорости

  1. Умножьте уравнение давления на k/μ. стр. 485
  2. Продифференцируйте по координате и переставьте производные. стр. 486
  3. Подставьте определение скорости фильтрации. стр. 486

Что это значит для данных модель

Скорость становится удобной расчётной величиной, поскольку именно она задана на галерее.

Вход
Уравнение давления, пьезопроводность, проницаемость и вязкость.
Выход
Уравнение переноса для скорости.
Где ломается
Прямой вывод не применим к независимо меняющимся коэффициентам.
Где здесь ручной труд специалиста
Входные данные
Уравнение давления, пьезопроводность, проницаемость и вязкость.
Ручные шаги
Записать смешанные производные и проверить подстановку Дарси по обеим частям.
Точки суждения
Проверить, действительно ли вынесенные коэффициенты постоянны.
Время
При постоянных параметрах выкладка короткая.
Типичные ошибки
Использовать неправильный знак скорости из-за другой ориентации оси.

Глубже

Место скрытого предположения модель

Коэффициенты выносятся из производных как постоянные. При пространственно переменных свойствах такая запись для скорости без проверки не переносится.

Новые понятия

Пьезопроводность (hydraulic diffusivity)
Способность среды передавать изменения давления диффузионным образом; коэффициент имеет размерность площади, делённой на время. модель
Закон Дарси (Darcy’s law)
Связывает скорость фильтрации с градиентом давления, проницаемостью и вязкостью; знак зависит от направления отсчёта. модель
Градиент давления (pressure gradient)
В одномерной задаче — производная давления по расстоянию, то есть изменение давления на единицу длины. модель
Скорость фильтрации (Darcy velocity)
Отношение объёмного расхода к полной площади поперечного сечения среды. модель
Проницаемость (permeability)
Свойство пористой среды пропускать жидкость под действием перепада давления. модель
Уравнение в частных производных (partial differential equation)
Уравнение с производными от функции нескольких аргументов. модель

Источник

Все утверждения шага с дословной цитатой автора и страницей книги (по PDF).

  1. Для вывода уравнение умножают на отношение проницаемости к вязкости. вывод

    «Для интегрирования уравнения пьезопроводности в данном случае умножим обе части уравнения (23.22) на $k/\mu$»

    — стр. 485

  2. Дифференцирование по координате даёт смешанную производную слева и третью пространственную производную давления справа. вывод

    «$$\frac{k}{\mu} \frac{\partial^2 p}{\partial x \partial t} = \frac{k}{\mu} \kappa \frac{\partial^3 p}{\partial x^3},$$»

    — стр. 486

  3. Перестановка порядка производных позволяет выделить один и тот же градиентный множитель в обеих частях. вывод

    «$$\frac{\partial}{\partial t} \left( \frac{k}{\mu} \frac{\partial p}{\partial x} \right) = \kappa \frac{\partial^2}{\partial x^2} \left( \frac{k}{\mu} \frac{\partial p}{\partial x} \right). \quad (23.32)$$»

    — стр. 486

  4. По закону Дарси этот множитель представляет скорость фильтрации в принятом направлении. наблюдение

    «$$\frac{k}{\mu} \frac{\partial p}{\partial x} = w(x, t),$$»

    — стр. 486

  5. Уравнение для скорости имеет тот же диффузионный вид и тот же коэффициент пьезопроводности. вывод

    «$$\frac{\partial w(x, t)}{\partial t} = \kappa \frac{\partial^2 w(x, t)}{\partial x^2}. \quad (23.33)$$»

    — стр. 486
