Как меняются частные производные

В книге: «Прямолинейно-параллельный фильтрационный поток упругой жидкости» стр. 482–483

≈ 6 мин ¶ Текст трудность: формализм

Опирается на: шаг 17 «Один аргумент вместо трёх» (предпосылка), шаг 6 «Как отбор меняет упругий запас» (предпосылка)

Суть

Через автомодельную переменную производные по расстоянию и времени выражают через производные по u.

Так уравнение в частных производных становится обыкновенным.

Затем наклон профиля обозначают новой неизвестной и понижают порядок уравнения.

Как это работает

Пересчёт производных

Производные по координате и времени пересчитывают по правилу дифференцирования сложной функции. Давление зависит от u, а u — от x и t. стр. 482

«Используя правило дифференцирования сложных функций, частные производные по координате и времени можно выразить через производные по безразмерной (автомодельной) переменной.»

— автор, стр. 482 вывод

Первая производная по координате равна производной профиля по u. Её умножают на производную u по расстоянию. стр. 482

«$$\frac{\partial P}{\partial x} = \frac{dP}{du} \frac{\partial u}{\partial x} = \frac{dP}{du} \frac{1}{2\sqrt{\kappa t}},$$»

— автор, стр. 482 вывод

Во временной производной множитель при производной профиля отрицателен. Он пропорционален отношению u ко времени. стр. 482

«$$\frac{\partial P}{\partial t} = \frac{dP}{du} \frac{\partial u}{\partial t} = \frac{dP}{du} \frac{x}{2\sqrt{\kappa}} \left( -\frac{1}{2\sqrt{t^3}} \right) = \frac{dp}{du} \left( -\frac{u}{2t} \right),$$»

— автор, стр. 482 вывод

Вторая производная по координате равна второй производной профиля по u. Её умножают на квадрат пространственного множителя. стр. 482

«$$\frac{\partial^2 P}{\partial x^2} = \frac{\partial}{\partial x} \left( \frac{\partial P}{\partial x} \right) = \frac{\partial}{\partial x} \left( \frac{dP}{du} \frac{1}{2\sqrt{\kappa t}} \right) = \frac{1}{2\sqrt{\kappa t}} \frac{d^2 P}{du^2} \frac{\partial u}{\partial x} = \frac{1}{4\kappa t} \frac{d^2 P}{du^2}.$$»

— автор, стр. 482 вывод

Обыкновенное уравнение

Подстановка этих производных даёт обыкновенное дифференциальное уравнение — уравнение для функции одного аргумента. стр. 483

«Подставляя найденные значения производных в уравнение (23.22), получим обыкновенное дифференциальное уравнение»

— автор, стр. 483 вывод

В нём вторая производная профиля компенсирует произведение первой производной на удвоенную u. стр. 483

«$$\frac{d^2P}{du^2} + 2u \frac{dP}{du} = 0, \quad (23.23)$$»

— автор, стр. 483 вывод

Решение ищут с уже полученными условиями для безразмерного давления. стр. 483

«которое должно быть решено при условиях (23.21).»

— автор, стр. 483 допущение

Понижение порядка

Наклон профиля выделяют в отдельную неизвестную ξ. стр. 483

«Для решения уравнения (23.23) обозначим $dP/du = \xi$, тогда уравнение (23.23) принимает вид»

— автор, стр. 483 вывод

Уравнение для наклона содержит только сам наклон и его первую производную. Это уравнение первого порядка. стр. 483

«$$\frac{d\xi}{du} + 2u\xi = 0. \quad (23.24)$$»

— автор, стр. 483 вывод

В пространственной производной время фиксировано. Во временной фиксирована координата. стр. 482

По шагам

Как получить уравнение для наклона

  1. Найдите производную u по расстоянию. стр. 482
  2. Найдите производную u по времени. стр. 482
  3. Ещё раз продифференцируйте пространственное выражение. стр. 482
  4. Подставьте производные в уравнение пьезопроводности. стр. 483
  5. Обозначьте наклон отдельной функцией. стр. 483
  6. Запишите уравнение первого порядка для наклона. стр. 483

Что это значит для данных модель

Производные профиля дают производные по исходным переменным с разными множителями.

Вход
Автомодельный профиль, время, координата и пьезопроводность.
Выход
Три частные производные для исходного уравнения.
Где ломается
В момент пуска выражения с временем в знаменателе не подставляют напрямую.
Где здесь ручной труд специалиста
Входные данные
Автомодельный профиль, время, координата и пьезопроводность.
Ручные шаги
Трижды применить правило цепочки и свести множители.
Точки суждения
Следить, какие величины остаются постоянными.
Время
Проверка знаков и степеней занимает больше времени, чем сама подстановка.
Типичные ошибки
Потерять минус во временной производной или второй пространственный множитель.

Аналогия модель

Замена координаты похожа на преобразование входа общей функции перед расчётом чувствительности.

Где аналогия перестаёт работать: Физическое время нельзя переставить местами с координатой: их множители различаются.
