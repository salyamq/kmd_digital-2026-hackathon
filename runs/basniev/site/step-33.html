Уравнение с одной переменной вместо двух

В книге: «Плоскорадиальный фильтрационный поток упругой жидкости. Основная формула теории упругого режима фильтрации» стр. 489

≈ 5 мин ¶ Текст трудность: формализм

Опирается на: шаг 32 «Свернуть расстояние и время в одну координату» (предпосылка), шаг 18 «Как меняются частные производные» (предпосылка)

Суть

Задача о скважине автомодельна, поэтому уравнение в частных производных сводится к обыкновенному по ξ.

Для этого производные по t и r выражают через производные по ξ.

Граничные условия тоже переписывают в безразмерном виде — без них решения нет.

Пороговая идея. После перехода к переменной подобия остаётся производная по одной координате, но граничные условия по-прежнему необходимы. модель

Как это работает

Зачем это нужно

Задача автомодельна: радиус и время входят в неё через одну переменную подобия ξ. Поэтому, по выводу автора, уравнение (23.40) можно свести к обыкновенному дифференциальному уравнению. Это уравнение с производными по одной переменной. стр. 489

«Таким образом, задача автомодельна, и уравнение (23.40) можно свести к обыкновенному дифференциальному уравнению.»

— автор, стр. 489 вывод

Пересчёт производных

Автор дифференцирует определение ξ из (23.43). Частные производные по t и r выражаются через производные по ξ. Например, ∂P/∂r = (dP/dξ)·1/(2√(κt)). стр. 489

«Продифференцируем (23.43) и найдем представление частных производных по независимым переменным $t$ и $r$ через производные по автомобильной переменной:»

— автор, стр. 489 вывод

Новое уравнение

Подстановка этих выражений в (23.40) даёт обыкновенное уравнение. В нём есть только P и ξ: d²P/dξ² + (1/ξ + 2ξ)·dP/dξ = 0. стр. 489

«Подставив полученные выражения в уравнение (23.40), получим обыкновенное дифференциальное уравнение»

— автор, стр. 489 вывод

Условия

Уравнение интегрируют с условиями из (23.41), переписанными в безразмерном виде. Вдали от стока P(ξ) = 1 при ξ → ∞. Значит, там давление равно контурному. стр. 489

«которое нужно проинтегрировать при условиях, полученных из (23.41) преобразованием к безразмерному виду,»

— автор, стр. 489 вывод

«$$P(\xi) = 1 \quad \text{при } \xi \to \infty,$$»

— автор, стр. 489 вывод

У стока, при ξ = 0, задано произведение ξ·dP/dξ. По (23.45) оно равно Q₀μ/(2πkhpк), то есть определяется параметрами отбора. стр. 489

«$$\left( \xi \frac{dP}{d\xi} \right)_{\xi=0} = \frac{Q_0 \mu}{2\pi k h p_\kappa}. \quad (23.45)$$»

— автор, стр. 489 вывод

Нюанс

Переход к ξ упрощает уравнение, но не заменяет граничные условия. Сведение опирается на автомодельность именно этой задачи. стр. 489

По шагам

Как свести уравнение к одной переменной

  1. Выразите производные по времени и радиусу через производные по ξ. стр. 489
  2. Подставьте их в радиальное уравнение (23.40). стр. 489
  3. Перепишите условия (23.41) в безразмерном виде. стр. 489

Цифры и условия

  • Вдали от стока P(ξ) = 1 при ξ → ∞. стр. 489
  • У стока при ξ = 0 произведение ξ·dP/dξ равно Q₀μ/(2πkhpк). стр. 489

Что это значит для данных по книге

Подставляют выражения для производных в радиальное уравнение и переносят условия в безразмерную форму.

Вход
Радиальное уравнение, переменная подобия, исходные условия.

Ручные шаги
Проверить цепное правило и отдельно преобразовать оба условия.
Точки суждения
Следить за множителями при дифференцировании по времени и радиусу.
Время
Проверка вручную особенно полезна при переносе условий.
Типичные ошибки
Потерять радиальный член уравнения или считать, что преобразование отменяет условия.
