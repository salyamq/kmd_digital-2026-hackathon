Путь по главе

Перед главой

Рекомендации из машинного анализа книги, подготовленного организаторами.

Что полезно знать заранее

  • Математика — Дифференциальное и интегральное исчисление, векторный анализ, обыкновенные и дифференциальные уравнения в частных производных, элементы тензорного исчисления.
  • Физика — Законы Ньютона, термодинамика, уравнение состояния.
  • Гидравлика — Книга сама начинает с основ механики сплошной среды, поэтому предварительное знание гидравлики желательно, но не обязательно.

Связи с другими главами

Главы I–V образуют фундамент механики сплошной среды; для читателя, знакомого с гидродинамикой, их можно пропустить. Главы VI–XVII — гидравлика и газодинамика. Главы XVIII–XXIV — подземная гидромеханика, требуют знания основ механики сплошной среды и законов сохранения. Приложение — справочный математический аппарат.

  • Главы I–II (механика сплошной среды) → Глава IV (жидкости) → Глава XIX (математические модели фильтрации)
  • Глава XVIII (закон Дарси) → Глава XX (установившаяся фильтрация) → Глава XXI (неоднородные пласты) → Глава XXII (метод суперпозиции)
  • Глава XIX (модели) → Глава XXIII (уравнение пьезопроводности) → Глава XXIV (приближённые методы)

Глава I и Приложение (индексная запись, векторный анализ, тензоры).

Ключевые термины

Скорость фильтрации (Darcy velocity / superficial velocity)
Связь с истинной средней скоростью через просветность: w = s·v (в общем случае тензор просветности). Глава XVIII
Просветность (surface porosity)
Авторы подчёркивают отличие просветности от пористости и вводят матрицу коэффициентов просветности. Глава XVIII
Упругий запас жидкости
ΔV_з = β* V0 Δp. Глава XXIII
Коэффициент упругоемкости пласта β* (bulk compressibility (formation compressibility))
β* = mβ_ж + β_с. Глава XXIII
Функция Лейбензона (Leybenzon function / pseudo-pressure)
P = ∫ρ(p)dp; для газа P ~ p². Глава XIX
Параметр Дарси
Da = 1 при справедливости закона Дарси. Глава XVIII
Двухчленный закон фильтрации (Форхгеймера) (Forchheimer equation)
grad p = -(μ/k)w - βρ/√k |w|w. Глава XVIII
Истинное газосодержание (true volumetric gas fraction / liquid holdup related)
φ = S_g/S; отличается от расходного газосодержания β. Глава XVII
Коэффициент пьезопроводности (hydraulic diffusivity)
κ = k/(μβ*), размерность L²/T. Глава XXIII
Тиксотропия / реопексия (thixotropy / rheopexy)
Классификация неньютоновских жидкостей по изменению напряжения во времени. Глава XVI
