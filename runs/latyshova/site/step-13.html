Простой разрез и сложный разрез

В книге: «Когда достаточно нескольких методов, а когда нужна количественная интерпретация» стр. 95

≈ 5 мин ¶ Текст трудность: неочевидное + распознавание

Опирается на: шаг 12 «Подписи пород на диаграммах ГИС» (предпосылка), шаг 11 «Как строят разрез скважины по ГИС» (переход к данным)

Суть

Сколько методов нужно, решает сам разрез.

Если породы ясно выражены, колонку можно составить по немногим методам, в терригенном разрезе — даже по одним электрическим.

В смешанном разрезе с разными порами и флюидами нужна количественная интерпретация вместе с геологическими сведениями.

Пороговая идея. Сложность задачи определяет разрез: в простом хватает электрических методов, в смешанном нужна количественная интерпретация с геологическими сведениями. модель

Как это работает

Простой случай

Автор делает вывод из таблицы признаков. Если разрез сложен породами с ясно выраженными свойствами, литологическую колонку можно составить по небольшому числу методов. Литологическая колонка — изображение разреза как последовательности пород. стр. 95

«литологическая колонка может быть вполне удовлетворительно составлена на основании данных небольшого числа методов»

— автор, стр. 95 вывод

Пример автора — терригенный разрез, где плотные слабоглинистые карбонатные породы имеют подчинённое значение. В нём задачу достаточно хорошо решают одни электрические методы. стр. 95

«задача может быть достаточно хорошо решена с помощью одних лишь электрических методов»

— автор, стр. 95 наблюдение

Сложный случай

Другое дело — смешанный разрез. В нём встречаются и терригенные, и карбонатные породы с разными типами пустот. Они насыщены водой разной минерализации, нефтью или газом. стр. 95

«можно осуществить лишь на основании количественной интерпретации геофизических данных с привлечением геологических сведений о характере разреза»

— автор, стр. 95 вывод

Тогда, по автору, разрез и особенно коллекторы выделяют лишь количественной интерпретацией. К ней привлекают геологические сведения о характере разреза. стр. 95

Соли, гипсы, ангидриты

В гидрохимических отложениях — отложениях солей, гипсов и ангидритов — важны два метода. Это метод рассеянного гамма-излучения, зависящий от плотности породы, и акустический метод. Они выделяют гипсы, ангидриты, известняки и соли по характерным для них константам. стр. 95

«большую роль играют методы рассеянного гамма-излучения и акустический, которые позволяют выделить гипсы, ангидриты, известняки и соли по характерным для них константам»

— автор, стр. 95 наблюдение

Практика по книге

Рис. 68 книги показывает комплекс диаграмм ГИС по участку терригенно-карбонатного разреза. По нему задача 91 предлагает построить колонку и отметить неоднозначные интервалы. стр. 95

«Комплекс диаграмм методов ГИС по участку терригенно-карбонатного разреза»

— автор, стр. 95 наблюдение

Цифры и условия

  • Условие: немногих методов хватает, только если породы в разрезе ясно выражены. стр. 95
  • Условие: одних электрических методов хватает в терригенном разрезе с подчинёнными плотными карбонатами. стр. 95

Что это значит для данных модель

Сложность разреза определяет, хватит ли простых правил по нескольким кривым или нужен количественный расчёт с геологическим контекстом.

Вход
тип разреза, комплекс кривых, геологические сведения
Выход
литологическая колонка, выделенные коллекторы
Где ломается
В смешанных разрезах с разной минерализацией вод правила по немногим методам дают ошибки.
  • гипотеза Автоматическую интерпретацию стоит разделять на режимы: простой разрез — правила, смешанный — количественная модель с геологическими признаками.
Где здесь ручной труд специалиста
Входные данные
диаграммы, сведения о районе
Ручные шаги
решение, достаточно ли простых признаков; количественный расчёт для сложных интервалов
Точки суждения
где интерпретация неоднозначна
Время

Аналогия модель

Как выбор сложности модели: для простых, хорошо разделимых данных хватает пары признаков и правил, для смешанных — нужна полноценная модель с контекстом.

Где аналогия перестаёт работать: Здесь «контекст» — геологические сведения, которых нет в самих кривых.
