Как строят разрез скважины по ГИС

В книге: «§ 19. Составление литологического разреза скважины по данным комплекса основных геофизических методов» стр. 92

≈ 5 мин ¶ Текст трудность: процесс/прибор + неочевидное

Опирается на: шаг 10 «Методы ГИС дополняют друг друга» (предпосылка)

Суть

Разрез строят в две операции: находят границы пластов, затем определяют породу каждого интервала.

Породу определяют по сумме признаков разных методов: чем больше признаков, тем точнее вывод.

Если состав пород неизвестен, сначала строят условную колонку по физическим признакам и уточняют её по образцам.

Пороговая идея. Литологию не «читают» с одной кривой: её собирают из суммы признаков разных методов, и при незнакомом разрезе сначала строят условную колонку по физическим признакам. модель

Как это работает

Две операции

Разрез скважины строят по комплексу диаграмм разных методов. Построение включает две операции. Первая — определить границы и толщины отдельных пластов. Вторая — оценить литологию выделенных однородных интервалов. стр. 92

«Построение разреза включает две операции: определение границ и толщин отдельных пластов и оценку литологической характеристики выделенных однородных интервалов.»

— автор, стр. 92 наблюдение

Сумма признаков

Границы и толщины находят способами, описанными раньше для отдельных методов. А литологию оценивают по сумме признаков на диаграммах разных методов. стр. 92

«Литологическую характеристику пород оценивают по сумме признаков, выявленных на диаграммах различных методов.»

— автор, стр. 92 наблюдение

Автор делает вывод: чем больше признаков породы установлено, тем точнее её можно определить. стр. 92

«Чем больше число признаков, характеризующих породу, установлено, тем точнее она может быть определена.»

— автор, стр. 92 вывод

Почему одного признака мало

Методы дают физические признаки пород. Но эти признаки часто общие для разных отложений. Поэтому вывод о породе по одному признаку ненадёжен. стр. 92

«существующие методы дают физические признаки пород, часто являющиеся общими для разных отложений»

— автор, стр. 92 наблюдение

Если порода совсем незнакома

Бывает, что ни минеральный состав, ни литология пород совсем неизвестны. Тогда строят условную колонку расчленения разреза — делят разрез на интервалы по физическим признакам, ещё не называя пород. стр. 92

«следует строить условную колонку расчленения разреза по физическим признакам, которую затем уточняют по данным петрофизических исследований образцов»

— автор, стр. 92 вывод

Затем колонку уточняют по петрофизическим исследованиям — лабораторным замерам свойств образцов. Образцы берут при бурении, это керн — цилиндр породы. Или отбирают боковым грунтоносом — устройством, которое берёт образцы из стенки скважины. стр. 92

По шагам

Как построить литологический разрез

  1. Определите границы и толщины отдельных пластов по диаграммам отдельных методов. стр. 92
  2. Оцените литологию каждого однородного интервала по сумме признаков разных методов. стр. 92
  3. Если состав пород неизвестен, постройте условную колонку по физическим признакам. стр. 92
  4. Уточните колонку по петрофизическим исследованиям образцов: керна или образцов бокового грунтоноса. стр. 92

Цифры и условия

  • Условие: условную колонку строят, когда минеральный состав и литология пород неизвестны. стр. 92

Частая ошибка модель

✗ Ошибка: Каротажная кривая — это и есть порода.

✓ На самом деле: Методы дают физические признаки, часто общие для разных пород; литологию получают по сумме признаков и уточняют по образцам. стр. 92

Что это значит для данных модель

Задача построения разреза — сегментация по глубине (границы пластов) плюс классификация сегментов по совокупности кривых, с калибровкой по образцам.

Вход
комплекс диаграмм ГИС, данные образцов
Выход
границы и толщины пластов, литология интервалов
Где ломается
Общие для разных пород признаки делают классификацию неоднозначной без образцов.
  • гипотеза Сегментация + классификация по многим кривым — естественная постановка для ML, где керн служит разметкой.
Где здесь ручной труд специалиста
Входные данные
диаграммы, керн, шлам
Ручные шаги
отбивка границ пластов, сопоставление признаков по каждой кривой
Точки суждения
какая порода соответствует набору признаков
Время
много ручной работы на каждую скважину
Типичные ошибки
вывод по одному признаку

Аналогия модель

Сегментация временного ряда с последующей классификацией сегментов по многим каналам.

Где аналогия перестаёт работать: Метки (керн) редки и привязаны к отдельным интервалам; разные классы могут давать одинаковые сигналы.

Как это делается сейчас модель

Сегодня колонку строят в программах интерпретации с автоматической увязкой кривых, но уточнение по керну остаётся обязательным.

Новые понятия

Разбиение разреза на интервалы по физическим признакам без названия пород, уточняемое потом по образцам. стр. 92
петрофизические исследования (petrophysical analysis)
Лабораторное измерение физических свойств образцов пород (керна). стр. 92 модель
боковой грунтонос (sidewall core sampler)

керн (core)
