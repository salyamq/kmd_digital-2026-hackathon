Три зоны течения в порах

В книге: «Пример 48. Критические параметры по фазовым проницаемостям» стр. 99

≈ 7 мин ⟳ Разбор источника трудность: процесс/прибор + неочевидное

Опирается на: шаг 21 «Два вида критических значений» (предпосылка, пример)

Суть

Граница «нефть / нефть с водой / вода» задаётся физикой течения в порах.

По лабораторным кривым фазовых проницаемостей находят, при какой водонасыщенности течёт только нефть, обе фазы или только вода.

Границы этих интервалов и есть критические значения водонасыщенности.

Пороговая идея. Граница «нефть / нефть с водой / вода» задаётся физикой течения: при какой водонасыщенности течёт только нефть, обе фазы или только вода. модель

По шагам

Как получить критические значения по фазовым проницаемостям

  1. Получите зависимость Pн = f(kв) для коллектора. стр. 99
  2. Получите зависимости фазовых проницаемостей по нефти и по воде от kв. стр. 99
  3. По кривым выделите интервалы kв: только нефть, нефть с водой, только вода. стр. 99

Разбор примеров из книги по книге

Пример 48. Три зоны течения по фазовым проницаемостям стр. 99

Условие. Межзерновой коллектор с мало изменяющейся глинистостью; есть зависимость Pн = f(kв) и кривые относительных фазовых проницаемостей по нефти и воде (рис. 70, чистый песчаный коллектор).

  1. Взять кривые относительной фазовой проницаемости по нефти и по воде от kв.
  2. Найти интервал kв, где течёт только нефть (от связанной воды до первой критической).
  3. Найти интервал двухфазного течения нефти и воды.
  4. Найти интервал, где течёт только вода (выше второй критической, до 1).

Итог. Получены три интервала водонасыщенности: однофазного течения нефти, двухфазного течения нефти и воды, однофазного течения воды; их границы — критические значения kв (рис. 70, а).

Цифры и условия

  • Условие примера: межзерновой коллектор с мало изменяющейся глинистостью. стр. 99
  • Нужны 3 зависимости: одна Pн = f(kв) и две фазовые проницаемости. стр. 99

Частая ошибка модель

✗ Ошибка: Коллектор либо отдаёт чистую нефть, либо чистую воду.

✓ На самом деле: Между зонами однофазного течения есть интервал двухфазного течения: коллектор даёт нефть с водой. стр. 99

Что это значит для данных модель

Лабораторные кривые фазовых проницаемостей переводят водонасыщенность в прогноз состава притока.

Выход

Кривые относятся к одному классу коллектора; при другой глинистости нужны свои кривые.

Аналогия модель

Как фазовая диаграмма состояний системы: по одной переменной (водонасыщенность) определяется режим работы.

Где аналогия перестаёт работать: Границы режимов размыты и зависят от класса породы, а не фиксированы.

Порядок

Перетащите пункты (мышью или пальцем за ⠿) или двигайте кнопками ↑ ↓.

  1. ⠿Течёт только вода
  2. ⠿Течёт только нефть
  3. ⠿Нефть и вода текут вместе
