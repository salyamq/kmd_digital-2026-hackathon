Зона неопределённости насыщения

В книге: «Критические значения Pн*, Pн** и область неоднозначной оценки насыщения» стр. 99–100

≈ 10 мин ◆ Решение на данных трудность: неочевидное + процесс/прибор

Опирается на: шаг 22 «Три зоны течения в порах» (предпосылка, пример)

Суть

Между «точно нефть» и «точно вода» лежит законная зона неопределённости — область двухфазного насыщения.

Её границы — критические значения Pн* и Pн: выше Pн* пласт даёт чистую нефть, ниже Pн — чистую воду.

Внутри зоны можно выбрать границу промышленного притока, например по равенству фазовых проницаемостей.

Пороговая идея. Между «точно нефть» и «точно вода» лежит законная зона неопределённости — двухфазное насыщение, где геофизика честно не даёт однозначного ответа. модель

Как это работает

Где геофизика честно не знает

Критические значения водонасыщенности kв* и kв ограничивают область двухфазного насыщения**. Там подвижны и нефть, и вода. Автор делает вывод: для промысловой геофизики это область неоднозначной оценки характера насыщения. стр. 99

«ограничивают область двухфазного насыщения или, с точки зрения промысловой геофизики, область неоднозначной оценки его характера»

— автор, стр. 99 вывод

Значениям kв* и kв соответствуют критические параметры насыщения Pн* и Pн. А минимальной, связанной водонасыщенности соответствует предельное для коллектора значение Pн max. стр. 99

«минимальному водонасыщению коллектора»

— автор, стр. 99 наблюдение

Правило трёх зон

Правило автора такое. Если Pн между Pн max и Pн*, коллектор даёт чистую нефть. Если Pн между Pн* и Pн, характер насыщения неопределённый. Если Pн между Pн и 1, коллектор даёт чистую воду. стр. 99

«характер насыщения неопределенный»

— автор, стр. 99 вывод

Граница промышленного притока

Критерий второго рода — граница внутри зоны неопределённости. Её выбирают по заданному соотношению нефти и воды в притоке, то есть по отношению фазовых проницаемостей. стр. 99

«т.е. заданному соотношению нефти и воды в притоке жидкости»

— автор, стр. 99 наблюдение

Пусть это соотношение равно 1. Тогда критические kв,кр и Pн,кр лежат в точке пересечения кривых фазовых проницаемостей по нефти и воде на рис. 70. стр. 99

«соответствуют точке пересечения кривых»

— автор, стр. 99 наблюдение

Примеры автора

Пример 49: по кривым рис. 70 находят kв* = 30%, kв,кр = 56%, kв = 80%. Им соответствуют Pн* = 10, Pн,кр = 3, Pн = 1,5. стр. 99

«По кривым относительной фазовой проницаемости на рис. 70, б находим»

— автор, стр. 99 наблюдение

Пример 50: чистый коллектор, кривая с αСП = 1. При Pн = 35 он даст чистую нефть. При Pн = 7 — нефть с небольшим количеством воды. При Pн = 2 — воду с признаками нефти, при Pн = 1,3 — чистую воду. стр. 100

«устанавливаем, что коллектор при испытании даст соответственно: чистую нефть; нефть с небольшим количеством воды; воду с признаками нефти; чистую воду»

— автор, стр. 100 наблюдение

По шагам

Как оценить насыщение по критическим Pн

  1. По кривым фазовых проницаемостей найдите kв*, kв,кр и kв**. стр. 99
  2. По зависимости Pн = f(kв) найдите соответствующие Pн*, Pн,кр и Pн**. стр. 99
  3. Сравните Pн пласта с критическими: выше Pн* — нефть, между Pн* и Pн — неопределённо, ниже Pн — вода. стр. 99

Разбор примеров из книги по книге

Пример 49. Критические kв и Pн по рис. 70 стр. 99

Условие. Коллектор характеризуется зависимостями на рис. 70. Определить критические значения kв и Pн.

  1. По кривым относительной фазовой проницаемости (рис. 70, б) найти kв* = 30%, kв,кр = 56%, kв** = 80%.
  2. По зависимости Pн = f(kв) (рис. 70, а) найти соответствующие значения Pн.

Итог. Pн* = 10, Pн,кр = 3, Pн** = 1,5.

Пример 50. Насыщение чистого коллектора по Pн стр. 100

Условие. Чистый коллектор (αСП = 1), зависимость на рис. 70, а; значения Pн = 35; 7; 2; 1,3.

  1. Взять кривую с модулем αСП = 1.
  2. Для каждого Pн определить область на графике.

Итог. Соответственно: чистая нефть; нефть с небольшим количеством воды; вода с признаками нефти; чистая вода.

Частая ошибка модель

✗ Ошибка: Геофизика всегда даёт однозначный ответ «нефть или вода».

✓ На самом деле: Между Pн* и Pн** характер насыщения неопределённый — это область двухфазного притока. стр. 99

Что это значит для данных модель

Выход — не два, а три класса: нефть, неопределённо (нефть с водой), вода; область неопределённости — законная часть ответа.

Вход
Pн пласта, критические Pн* и Pн** объекта
Выход
класс насыщения или «неопределённо»
Где ломается
Критические значения свои для каждого коллектора; при других кривых фазовых проницаемостей границы сдвигаются.
  • гипотеза Модель насыщения стоит строить с классом «неопределённо» вместо бинарного ответа.
Где здесь ручной труд специалиста
Входные данные
кривые фазовых проницаемостей и Pн = f(kв) по керну
Ручные шаги
снятие критических точек с графиков, сравнение Pн пластов
Точки суждения
что делать с пластами в зоне неопределённости
Время
графические операции по каждому классу коллектора
Типичные ошибки
игнорировать зону неопределённости

Аналогия модель

Классификатор с зоной отказа (reject option): в пограничной области честнее ответить «не уверен».

Где аналогия перестаёт работать: Ширина зоны здесь задана физикой течения (фазовые проницаемости), а не порогом уверенности модели.
