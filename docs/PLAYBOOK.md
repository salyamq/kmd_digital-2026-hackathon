# Плейбук команды

## Правила, которые не нарушаем

1. **Учебный слой — единственный источник правды.** Курс, задания, ролики собираются из `layer.json`.
   Ошибка исправляется в слое (override) и пересобирается одной командой.
2. **Руками правим только `overrides/` и только с записью в журнал** (`python -m kmd edit ...`, минуты честно).
   Правка готового HTML, JSON шагов или монтажа — запрещена: на тесте она не повторится.
3. **Ничего под конкретную главу в коде.** Если на главе что-то сломалось — чиним общий код или промпт
   и перегоняем все главы. Предметное — только в `domains/<домен>/`.
4. **Цитата и страница у каждого утверждения.** Код проверяет, что цитата на этой странице PDF и что
   каждое число есть в главе. Что написала модель — помечено «модель».
5. **Факты рисует код.** Кадры и иллюстрации классов A/B — из модели состояния; генеративных картинок нет.
   Преувеличения подписаны числом, на каждом кадре метка «реальные данные / симуляция / схема».

## Порядок работы на главе

1. `chapters/<id>.yaml` → `make run CH=<id>`.
2. Открыть `runs/<id>/verify_report.json`: ошибок быть не должно; предупреждения просмотреть.
3. Пройти курс как новичок (телефон 390 px и десктоп): каждое «не понял» — правка в слое или промпте.
4. Видеоузел: `kmd scenes` → спецификация сцены → **проверка ментором по чек-листу физики до рендера**
   → `kmd video` → паспорт (темп 110–150 сл/мин, −16 LUFS, WER ≤ 10 %, синхрон ≤ 0,5 с, список «проверить на слух»).
5. `python -m kmd.metrics` — минуты и деньги на узел.

## Заморозка и тест

1. Перед выдачей тестовых глав: `make test`, `pip freeze > requirements.lock`, тег `git tag freeze-<дата>`, push.
2. После тега код, `prompts/` и `domains/` не меняются. Для каждой тестовой главы: yaml → `make run`.
3. Любая ручная правка на тесте — override + `kmd edit` с минутами. Цель — до 30 человеко-минут на главу.
4. Сдвиг (другой домен): `python -m kmd domain <домен> --from-chapter <id>` → проверить пакет глазами
   (минуты — в журнал) → `make run`.
5. Закладки: `python -m kmd check <пакет> --chapter <id>`.

## Роли

- **ИТ:** запуск конвейера, LLM-провайдер, очередь, сборка.
- **Геолог/геофизик:** просмотр `verify_report`, спецификаций сцен и курса; правки — только override.
- **Педагог/сценарист:** проходит курс как новичок, проверяет сценарии роликов на слух.
- **Дизайн:** стайлгайд `domains/<домен>/styleguide.json`, шаблоны сцен `kmd/visuals/templates/`.
