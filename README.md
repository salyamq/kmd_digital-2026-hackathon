# Глава → курс

Переносимый конвейер: глава учебника по геологии/геофизике → проверенный **учебный слой** →
**демо-курс для новичка** (путь из шагов, страницы шагов со «стр. N», задания с проверкой, карточки,
конспект, карта связей, иллюстрации кодом, ролики 9:16 и 16:9).

## Посмотреть готовые курсы

Откройте в браузере файл (сервер и интернет не нужны):

| Барабошкин, §1.2 | контроль | `runs/baraboshkin/site/index.html` |

Ролики и их паспорта: `runs/<глава>/video/<узел>/`.

## Запуск

```bash
make setup                      # Python 3.12 venv + зависимости (нужны uv, ffmpeg; для запасного голоса — espeak-ng)
export KMD_DATA=~/kmd_data      # папка с книгами: md/*.md (с метками <!-- page N -->) и pdf/*.pdf
make run CH=latyshova           # весь конвейер для главы → runs/latyshova/site/index.html
```

Для рендера видео установите FFmpeg и Cairo. На Linux для установки pycairo также нужны
`libcairo2-dev` и `pkg-config`. Ролик для конкретного узла можно собрать вместе с курсом:

```bash
make run CH=latyshova VIDEO_NODE=geo.latyshova.s20.01 VIDEO_FORMAT=short
# Или отдельно, с обновлением существующего сайта:
python -m kmd video latyshova geo.latyshova.s20.01 --format short
```

Основной конвейер использует импорт, проверку источников, маршрутизацию и сборку курса из
`main`. Видео по умолчанию собирает `vidpipe` из `feature/video-pipeline`: он получает узел
и страницы из учебного слоя, применяет доменный пакет и формирует сценарий, кадры, субтитры,
QA-отчёт и паспорт. Форматы команды `short` и `long` соответствуют 9:16 и 16:9.
MP4 и паспорт доступны в `runs/<глава>/video/<узел>/`, материалы рендера и QA —
в `runs/<глава>/tmp/vidpipe/<узел>/<формат>/`.

Планировщик по правилам работает без ключа LLM. `--planner llm` включает настроенный провайдер.
По умолчанию озвучивает Microsoft. При сбое весь ролик переозвучивается доступным локальным
движком. Для русского Piper при первой сборке загружает модель голоса. Локальный движок
можно выбрать через `--tts piper`, `--tts rhvoice` или `--tts espeak`.
Для прогона рендера без озвучки есть
`--tts none` (в Makefile — `VIDEO_TTS=none`). Старый рендерер доступен через
`--video-engine legacy`. Готовые ролики из репозитория подключаются при обычной сборке курса.

При запуске без ключа LLM конвейер переиспользует ответы из `runs/<глава>/llm/`, сохранённые сцены
и перерисовки. Отсутствующие сцены и перерисовки в этом режиме не блокируют сборку курса.
Чтобы запросить новые, запустите `.venv/bin/python -m kmd scenes <глава>` или добавьте `--with-scenes`
к команде `.venv/bin/python -m kmd run <глава>`. Отсутствующие ответы для обязательных этапов
по-прежнему попадают в очередь и возвращают код 3.

### Новая глава (тест)

1. Положите md и pdf книги в `$KMD_DATA`, создайте `chapters/<id>.yaml` по образцу (страницы PDF,
   строки начала и конца главы, домен, язык). Код менять не нужно.
2. Укажите LLM в `.env` (любой из вариантов):
   ```
   ANTHROPIC_API_KEY=...            KMD_LLM_MODEL=<модель>
   # или OpenAI-совместимый API (OpenAI, OpenRouter, локальный vLLM/Ollama):
   OPENAI_API_KEY=...  OPENAI_BASE_URL=...  KMD_LLM_MODEL=<модель>
   ```
   Без ключа работает режим очереди: запросы пишутся в `runs/<id>/llm/pending/`, на них отвечает
   оператор/агент (`python -m kmd llm show|answer`), ответ проверяется JSON-схемой и кэшируется.
3. `make run CH=<id>`. Код выхода 3 значит «есть неотвеченные запросы к LLM» (режим очереди).
4. Ролик на назначенный узел: `python -m kmd video <id> <node_id> --format short|long`.

### Новый домен (сдвиг)

`python -m kmd domain <домен> --from-chapter <id>` — черновик доменного пакета (глоссарий RU/EN,
заблуждения, чек-лист физики, ИТ-мосты, словарь ударений) в `domains/<домен>/` с замером времени
в `BUILD.json`. Движок о геологии ничего не знает: всё предметное лежит в `domains/`.

### Исправить факт и пересобрать (одна команда)

Сгенерированные файлы руками не правятся. Правка — это патч узла в `overrides/<глава>/<node_id>.json`
и строка в журнале:

```bash
python -m kmd edit latyshova --target geo.latyshova.s20.04 --minutes 3 --what "уточнено условие применимости"
make rebuild CH=latyshova       # слой → проверка → маршрутизация → шаги → сайт
make rebuild CH=latyshova VIDEO=1  # также пересобрать имеющиеся ролики
```

Журнал ручных правок: `edits/journal.jsonl` (минуты, коммит). Метрики стоимости:
`python -m kmd.metrics` → `runs/metrics.json` (человеко-минуты и деньги на узел и на минуту видео).

### Модуль проверки (закладки)

```bash
python -m kmd check <папка_пакета> --chapter <id>     # → findings.json: ошибка, тип, тяжесть, исправление, страница, цитата
```
Формат внешнего пакета: `schemas/external_package.schema.json`.

## Как устроено

`docs/ARCHITECTURE.md` — этапы и их артефакты; `docs/PLAYBOOK.md` — порядок работы команды;
`MANIFEST.yaml` — модели и инструменты, что уходит во внешние сервисы; `docs/TZ.md` — задание.

```
глава (md + сканы) → ingest → units.json (единицы главы со страницами)
  → layer → layer.json (учебный слой: узлы, утверждения с цитатой и страницей) + coverage.json (100 %)
  → verify (код: цитата есть на странице, каждое число есть в источнике, покрытие, ссылки)
  → route → routing.json (формат узла по типу трудности и видеоёмкости)
  → scenes → спецификации сцен (объекты, параметры, инварианты, допущения, класс кадра)
  → course → страницы шагов, задания, карточки и иллюстрации
  → video (по запросу) → vidpipe → MP4, QA и паспорт
  → site/ (офлайн-курс с доступными роликами)
```

Тесты: `make test`.
