# Чек-лист корректности: Подземная гидромеханика и гидродинамические исследования скважин

(Черновик LLM по главе barenblatt; общие пункты — из базового пакета.)

## Процессы и причинность
- [ ] Возмущение давления распространяется диффузионно: зона влияния растёт как √(κt), без постоянной скорости фронта.
- [ ] Давление у работающей скважины снижается (депрессия), после остановки — восстанавливается; знак изменения верен.
- [ ] Флюид течёт от высокого давления к низкому; поток к скважине направлен из пласта.
## Модели и допущения
- [ ] Названы допущения модели: однородный пласт, слабосжимаемая жидкость, упругий режим, плоскопараллельный или радиальный поток.
- [ ] Указано, применимо ли решение для бесконечного пласта (время меньше времени достижения границ).
- [ ] Масштабные законы верны: характерное время ~ L²/κ, давление на скважине ~ ln t.
## Измерения и данные
- [ ] Измеряется давление и дебит; проницаемость, пьезопроводность, гидропроводность — вычисляются по модели.
- [ ] Учтены несовершенство скважины, загрязнение призабойной зоны и послеприток при интерпретации КВД.
- [ ] Графики p(ln t) подписаны; выделен участок, по которому ведётся расчёт.
## Масштабы и числа
- [ ] Характерные времена правдоподобны для размеров (часы между скважинами, годы для водонапорной системы).
- [ ] Радиус скважины на рисунках не сопоставим с расстоянием между скважинами без подписи преувеличения.
